# DisableGrowthMeter
#### Experimental fix to stop the Maneater from growing up after its growth meter gets too high

## This mod is no longer maintained
I no longer play Lethal Company frequently enough to maintain this mod. All content here is an archive of the project as of today.
While the mod may still function, it is not guaranteed to, and if it breaks I am unable to help you.
See Notes for permission to re-use this project.

Original description below
  
  
## Usage
Install the mod from Thunderstore or r2modman(Plus).
To completely disable transformation, I suggest [NormalBabies](https://thunderstore.io/c/lethal-company/p/Zorfi/NormalBabies/).

## Notes
- This mod alone does ***not*** attempt to disable transformation altogether on its own. This mod only stops the growth meter from increasing; other calls to immediately transform will still trigger. **Use in tandem with [NormalBabies](https://thunderstore.io/c/lethal-company/p/Zorfi/NormalBabies/) if you want to disable this!**
- I have released this mod into the public domain. Anyone willing to maintain this mod may do so; credit is appreciated, but not required. The code is available on my [GitHub](https://github.com/restorerootfs/DisableGrowthMeter).
